#### Overview

The current tool for booking, **managing** a work trip as well as filing an expense report is slow, confusing, and inefficient for users. The goal is to design an AI-powered platform that helps users book flights, hotels, and other necessary items for work travel as well as track expenses and streamline the process of filing an expense report for review and approval by managers.

#### Objective

Build an AI-powered platform to help employees plan, book, and manage work-related trips while streamlining expense logging and approval. This new tool should reduce the manual effort in booking and expense filing as well as improve accuracy and increase managerial approval and reimbursement.

#### Problem statement

Users have difficulty booking and managing work trips while also tracking expenses for approval. The current tool is fragmented and requires manual booking across multiple services, while managers report errors in expense entries resulting in approval and reimbursement delays.

![concur intro](/assets/project/concur/intro-concur.png)

#### Discovery

Employees: User interviews with employees revealed frustrations with booking tools. “Complicated”, “stressful” and “confusing” were common feedback. Users also reported difficulty with keeping track of receipts, understanding per diem allotments, and logging all that information to the expense tracking tool.

Managers: Users reported expense overload and low approval rates resulting in multiple rounds of time-consuming reviews which affected productivity.

After interviews, an audit of the existing tool revealed how each function relates to tasks users need to complete like booking flights, hotels, tracking food expenses. Additionally, an audit of competitor tools, like expensify, identified areas to address feature gaps and pain points in the user experience.

![concur brainstorm](/assets/project/concur/concur-brainstorm.png)

#### Design process

I began by synthesizing the feedback from users and creating an empathy map for what the user is doing, feeling, and thinking as they move through the experience of using the existing tool. This helped to identify opportunity points to improve the experience for the new tool.

Next, I outlined the expected user journey from end-to-end and began exploring ideas of what each stage would entail with new features such as an AI-assistant to recommend the best hotels/flights for users based on company policy, user preferences and cost optimization.

Additionally, I explored ideas for a smart receipt scanning, per diem budget tracking, and auto-categorization of expenses with AI flagging any potential errors.

Finally, I explored ideas for the final review and submission of expense reports with reminders and nudges to managers. Future improvements from user feedback include a seamless integration with email, slack, and HR tools to help streamline these processes.
